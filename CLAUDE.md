# CLAUDE.md – PerfPulse (PerformanceMonitor)

Working notes for this repository.

## Build & publish

Requirements: .NET 10 SDK, Windows 10/11, [Inno Setup 6](https://jrsoftware.org/isinfo.php)
(`winget install JRSoftware.InnoSetup`).

```powershell
# Run from source
dotnet run --project PerformanceMonitor

# Build the self-contained installer (-> dist\PerfPulse-Setup-<ver>.exe)
powershell -ExecutionPolicy Bypass -File build.ps1 -Version 1.0.0
```

The installer is self-contained (ReadyToRun, win-x64), so the target machine needs no
.NET runtime. Assets (icon, installer graphics) are generated by `tools\make-assets.ps1`,
which `build.ps1` runs automatically (skip with `-SkipAssets`).

Publishing a new installer version:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1 -Version <new-ver>
gh release create v<new-ver> dist\PerfPulse-Setup-<new-ver>.exe --title "PerfPulse <new-ver>" --notes "..."
```

Settings and scan history live in `%AppData%\PerfPulse`.
